| | |

| 🔎 **AI search in plain language** | Ranked profiles in under 0.2 s, with the reason for each pick, explained by an LLM running locally (Ollama) |
| ⚡ **Built to scale** | 6 combined filters in **54 ms on 100,000+ profiles** (PostgreSQL + pgvector) |
| 🧪 **Tested end to end** | 70 server tests (Testcontainers) and 104 real-browser checks (Playwright), desktop and mobile |
| 🔐 **Privacy by design** | Signed media links, consent tracking, data export and deletion, nightly retention purge |
